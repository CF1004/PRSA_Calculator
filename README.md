# PRSA Growth Calculator

📊 **A simple Excel tool for estimating the inflation-adjusted future value of a PRSA using monthly contributions and compound growth.**

This calculator lets you enter your own values for starting capital, monthly input, annual return, years, and inflation to see the projected result in today's euros.

## ✨ What it does

- Calculates the inflation-adjusted future value of a PRSA
- Uses monthly contributions and monthly compounding
- Lets you test different scenarios quickly in Excel
- Shows the result in today's euros after inflation adjustment

## 🧮 How to use

1. Download the Excel file.
2. Enter whole numbers in cells **A5, B5, C5, D5, and E5**.
3. View the result in **F5**.
4. Rows **6 to 10** can also be used for additional scenarios.

## 📌 Notes

- Enter annual return and inflation as whole percentages  
  - `7` = 7%  
  - `2` = 2%
- The formula assumes monthly compounding and end-of-month contributions.
- The result is shown in today's euros after adjusting for inflation.

## 💡 Purpose

I built this as a small Excel portfolio project to create a practical and visually clean pension growth calculator that can be used to test different PRSA scenarios.
